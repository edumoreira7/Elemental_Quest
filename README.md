# Elemental Quest

Jogo de plataforma 2D feito no Unity 6000.5.8f1.

Abra esta pasta pelo Unity Hub, carregue `Assets/Scenes/Inicio.unity` e pressione Play.
Consulte [COMO_JOGAR.md](COMO_JOGAR.md) para controles, objetivos e orientações de edição.

O projeto versiona `Assets`, `Packages` e `ProjectSettings`, preservando os arquivos `.meta`.
As pastas geradas pelo Unity são excluídas pelo `.gitignore` existente.
